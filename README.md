## 📌 Overview

This is a professional portfolio website for **Lilian Nyong** – a Registered Nurse (RN) with 2+ years of clinical experience transitioning into telehealth and virtual patient support.

The portfolio is designed to showcase her clinical expertise, telehealth services, work samples, certifications, and professional background in a modern, interactive, and healthcare-focused layout.

## ✨ Key Features

### 🏥 **Healthcare Visual Identity**
- **ECG Pulse Animation** – Animated heartbeat line in the hero background
- **Medical Floating Icons** – Stethoscope, heartbeat, pills, and other medical icons rising from the bottom
- **Medical Cross Shapes** – Subtle rotating crosses in the background
- **Pulse/Spinning Ring** – Dynamic ring animation around the profile image

### 🎥 **Introductory Video**
- Half‑width layout with video + text side‑by‑side
- Autoplay with sound off (muted)
- **Sound toggle button** – click to unmute/mute
- Smooth fade‑in on scroll

### 🔄 **Continuous Work Samples Carousel**
- **Smooth, continuous glide** – no jarring jumps
- Pauses on hover, resumes on leave
- Larger 2‑column layout on desktop (1 column on mobile)
- 10+ work samples showcasing clinical and telehealth projects

### 📊 **Interactive Elements**
- **Trust Badges** – Animated counters (100+ Patients, 50+ Telehealth Sessions, 6 Clinical Roles)
- **Stats on Experience Cards** – Patient impact numbers revealed on hover
- **Typewriter Effect** – Dynamic role phrases in the hero section
- **3D Tilt** – Interactive tilt effect on profile image and cards
- **Custom Cursor** – Branded cursor with hover states

### 📱 **Responsive Design**
- Fully responsive across all devices (desktop, tablet, mobile)
- Mobile‑optimized navigation with hamburger menu
- Touch‑friendly carousels and interactions

This portfolio is deployed using **GitHub Pages**.

### Live URL:

### To deploy your own version:

1. **Fork or clone this repository**
   ```bash
   git clone https://github.com/Nurse-lilian/portfolio.git
   cd portfolio
Update assets – Replace images, video, and PDF with your own files.

Enable GitHub Pages:

Go to Settings → Pages

Select main branch → / (root) folder

Click Save

Your site will be live at https://[your-username].github.io/portfolio/
